Se desarrollará una base de datos relacional para un sistema de venta de libros   mediante catálogo online. El sistema permitirá administrar un catálogo de libros y registrar las operaciones necesarias para realizar compras, controlar el stock, gestionar clientes, registrar pagos y conservar el precio aplicado a cada libro al momento de una venta.
Los usuarios del sistema se clasificarán mediante los roles Administrador, Vendedor y Cliente. Los clientes deberán encontrarse registrados para poder realizar compras y podrán disponer de una o varias direcciones asociadas a su cuenta.
Cada libro contará con la siguiente información: ISBN, título, editorial, género, autor o autores, stock disponible y precio actual. Un libro podrá estar asociado a uno o varios autores. El sistema permitirá que una compra contenga diferentes libros y distintas cantidades de cada uno.
